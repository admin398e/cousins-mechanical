# ---------------------------------------------------------------------------
# What is deliberately NOT listed here, and why.
#
# A Disallow on a URL that does not exist is permanent. The crawler is told not
# to look, so it never learns the page is gone, and Search Console files it
# under "Blocked by robots.txt" for good. A 404 clears itself in a few weeks
# and needs nobody to remember it.
#
# Eleven rules used to sit here for paths that all answer 404 — /ukvd, /v1/,
# /bookings, /messages, /track, /notify, /service-requests, two old pricing
# worksheets and the un-hydrated "{{ token }}" URLs the booking page used to
# emit. Every one of them was a page Google was forbidden to check and could
# therefore never drop. They are gone from this file so they can 404 and fall
# out of the report.
#
# The staff portals are not blocked here either. Blocking them meant Google
# could not read the noindex on them, which is the tag that actually removes a
# page from the index; robots.txt only stops the fetch. They now answer with
# X-Robots-Tag: noindex, nofollow, which is the instruction that works.
# ---------------------------------------------------------------------------
